# Book Reading List

The application allows a user to:

1. Search for books using the free public books API.
2. View search results.
3. Add books to a personal reading list.
4. Record their reading status.
5. Remove books from the reading list.
6. Filter the reading list.
7. Persist the reading list using localStorage.
